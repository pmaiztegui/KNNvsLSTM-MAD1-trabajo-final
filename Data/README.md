# Datos

En este proyecto se trabajó con el dataset CICIDS-2017 creado por el Canadian Insititute for Cybersecurity (CIC).

Debido al tamaño del dataset original, los archivos no se incluyen directamente en este repositorio.

Estos pueden descargarse en el siguiente link, correspondiente a la web oficial del CIC: https://www.unb.ca/cic/datasets/ids-2017.html

Parte de nuestra tarea fue preprocesar los datos. Eliminamos filas duplicadas, tratamos valores infinitos y faltantes, agrupamos etiquetas en 7 clases, normalizamos las características, aplicamos SMOTE, etc. Estos pasos fueron documentados en el notebook.
